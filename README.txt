CS 315 - Homework 1
Personal Portfolio Website

FILES
- index.html: portfolio content and semantic HTML structure
- style.css: colors, spacing, borders, layout, and responsive styling

DESIGN IDEA
The portfolio uses a basketball theme because it reflects one of my interests
and makes the site more personal. The header is arranged like a scoreboard,
the skills are called the starting lineup, and projects are career highlights.
The orange, black, and light court colors connect the sections visually.

BEFORE SUBMITTING
1. Read every section and confirm that it accurately describes your experience.
2. Replace or remove any technology or project detail that you cannot explain.
3. Upload index.html and style.css to your public_html directory on ICE.
4. Set the permissions required by your instructor's ICE demonstration.
5. Open the real ICE website URL in a private/incognito browser window.
6. Confirm that the page loads and the navigation links work.
7. Replace YOUR_ICE_WEBSITE_URL in the submission PDF source if necessary,
   and submit the final clickable PDF plus the ZIP file to Brightspace.

SEMANTIC ELEMENTS REQUIRED BY THE ASSIGNMENT
- header: introduction at the top of the page
- nav: links to each page section
- main: the primary portfolio content
- section: groups related content
- article: each experience or project is self-contained
- footer: author and course information
