# Basketball Portfolio

A personal portfolio site with a basketball theme. The header works like a scoreboard, skills are the "starting lineup" and projects are "career highlights", all in orange, black and court colors.

**Live site:** https://tutumtetwa.github.io/basketball-portfolio/

## Sections

About Me · Technical Skills · Professional Experience · Projects and Coursework · Career Goals

## Tech

Semantic HTML5 (`header`, `nav`, `main`, `section`, `article`, `footer`) and responsive CSS. No frameworks and no build step.

| File | Description |
|---|---|
| `index.html` | Page content and structure |
| `style.css` | Colors, layout and responsive styling |

Companion project: [Student Profile Builder](https://github.com/tutumtetwa/student-profile-builder).

Built for CS 315 (Internet Programming), Fall 2026, by Tutu Mtetwa.
